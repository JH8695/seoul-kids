# 서울 아이 체험

서울시 공공서비스예약(yeyak.seoul.go.kr)에 흩어진 숲체험·박물관·어린이 체험을 **한 화면에서 찾고**,
날짜를 골라 그날 열리는 프로그램과 접수 기간을 보는 개인용 모바일 웹앱 (React + Vite).

- 데이터: 서울 열린데이터광장 "공공서비스예약정보" OpenAPI (교육 + 문화행사)
- 아이별 대상 판정(유치원 / 초등), 분야별 필터(🌳숲·자연 🏛️박물관·전시 🎨만들기·체험 🔬과학 🏺역사·문화)
- "선택한 구"(설정에서 자치구 선택) / 서울 전체, 달력 모드, 접수예정·마감임박 탭
- 프로그램명·장소 검색, 무료만 보기, 찜하기(이 기기에만 저장)
- 같은 프로그램의 여러 회차는 카드 하나로 묶고 날짜 칩으로 보여줘요. 제목의 날짜·요일("(12/7)", "(휴일, 토)")은 달력에 그대로 반영해요.
- 정렬: 접수 일정 순 / 이용일 순 / 가까운 구 순(구별로 묶어서)
- 단체 전용·장애인·특정 계층(사회적 배려 등) 대상은 자동으로 숨김, 대상이 "제한없음"인 것은 어린이·가족 언급이 있을 때만 기본 노출
- 예약은 서울시 사이트에서 직접 해요. 이 앱은 로그인 정보를 받지 않아요.

## 실행

```
npm install
npm run dev          # 처음에는 샘플(실제 프로그램 10건)이 보여요
```

## 실데이터 연결

1. 서울 열린데이터광장(data.seoul.go.kr)에서 발급받은 인증키를 준비
2. 내 컴퓨터에서 한 번 확인:
   ```
   SEOUL_API_KEY=인증키 npm run collect     # public/data/courses.json 생성
   npm run dev
   ```
   인증키는 파일이나 채팅에 적지 마세요. 환경변수로만 넘겨요.
3. 자동 갱신·배포(GitHub Pages, 3시간마다):
   - 저장소 Settings > Secrets and variables > Actions > `SEOUL_API_KEY` 로 인증키 등록
   - Settings > Pages > Source 를 **GitHub Actions** 로 설정
   - push 하면 배포 → 폰 브라우저에서 "홈 화면에 추가"

## 고칠 곳

| 하고 싶은 것 | 파일 |
| --- | --- |
| 거리 기준점, 기본 자치구, 분야 이름·이모지, 아이 기본값 | `src/data/config.js` |
| 수집할 서비스 추가(체육시설 등) | `scripts/seoul.mjs` 의 `SERVICES` |
| 분야 분류 규칙, "매주 토" 같은 요일 읽기 | `scripts/seoul.mjs` |
| 대상 문구(유아/초등/가족 등) 판정 규칙 | `src/lib/grade.js` (+ `test/grade.test.mjs`) |
| 단체·장애인·특정 계층·"제한없음" 처리 규칙 | `src/lib/audience.js` (+ `test/audience.test.mjs`) |
| 제목에서 날짜·요일·학년 읽기, 회차 묶기 | `src/lib/title.js` (+ `test/title.test.mjs`) |
| 구 중심 좌표(가까운 구 순) | `src/data/config.js` 의 `AREA_CENTERS`, `HOME.area` |

`npm test` 로 수집 변환과 대상 판정 규칙을 점검해요.

## 알아둘 점

- 서울시 목록에는 회차별 날짜가 없고 이용 "기간"만 있어요. 제목·상세 글에 "매주 토" 같은 요일이 있으면 그날만,
  없으면 기간 안의 모든 날에 연하게(점선) 표시해요. 정확한 날짜는 예약 사이트에서 확인하세요.
- 거리는 직선거리(대략)예요. 기준 좌표는 `config.js` 에서 바꿀 수 있어요.
