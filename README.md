# 서울 아이 체험

서울시 공공서비스예약(yeyak.seoul.go.kr)에 흩어진 숲체험·박물관·어린이 체험을 **한 화면에서 찾고**,
날짜를 골라 그날 열리는 프로그램과 접수 기간을 보는 개인용 모바일 웹앱 (React + Vite).

- 데이터: 서울 열린데이터광장 "공공서비스예약정보" OpenAPI (교육 + 문화행사)
- 아이별 대상 판정(유치원 / 초등), 분야별 필터(🌳숲·자연 🏛️박물관·전시 🎨만들기·체험 🔬과학 🏺역사·문화)
- "선택한 구"(설정에서 자치구 선택) / 서울 전체, 달력 모드, 접수예정·마감임박 탭
- 프로그램명·장소 검색, 무료만 보기, 찜하기(이 기기에만 저장)
- 같은 프로그램의 여러 회차는 카드 하나로 묶고 날짜 칩으로 보여줘요. 제목의 날짜·요일("(12/7)", "(휴일, 토)")은 달력에 그대로 반영해요.
- "관심 없어요"로 프로그램(모든 회차)을 숨기고, "숨긴 것 다시 보기"에서 되살려요(이 기기에만 저장).
- 한 달 내내 열려 있는 시설 예약("운영 안내", "전시해설 예약" 등)은 "상시 운영" 섹션에 따로 접어 둬요.
- 메모와 "내 날짜"(예약 하나 단위): 카드의 📝 메모에서 적으면 달력에는 내가 적은 날짜에만 찍혀요. 설정에서 다른 기기로 내보내기/가져오기.
- 같은 프로그램의 회차를 "이 회차만 남기기"로 정리, "숨긴 것 다시 보기"에서 "이 회차만 숨기기 취소".
- 폰은 목록이 먼저 뜨고, 분야·아이·구·옵션은 버튼을 눌러 선택 창에서 골라요. 요일을 고르면 요일이 확인된 프로그램이 먼저, 모르는 건 "요일 확인 필요"로 접혀요.
- 구글 로그인으로 폰·PC 동기화(찜·숨김·메모·설정). 로그인 전에는 이 기기에만 저장돼요. 합치기 링크로도 옮길 수 있어요.
- 상세 설명에 적힌 운영일("운영일 : 17일,24일(토)", 표의 회차 줄 등)을 읽어 달력에 정확한 날짜로 표시해요(서울시 이용 기간이 실제와 다른 경우가 많아서). "연간"·"상설"·서울형 키즈카페 같은 상시 이용은 "상시 운영"으로 접어 둬요.
- 제목을 누르면 도서관 앱으로 이동하는 메뉴(▾)가 열려요. 달력은 앞뒤 달에 몇 개가 있는지 보여주고, 카드의 날짜를 누르면 달력으로 이동해요.
- 설명에서 읽은 일정("매주 토요일", "토요일 2,3주", "8월 제외", 휴강 날짜, 휴관 요일)을 달력에 반영하고, 어디서 읽었는지 "읽은 문장"을 보여줘요. 어린이집 대상은 단체로, 난임·임산부 대상은 성인 대상으로 숨겨요.
- 정렬: 가까운 구 순(기본) / 접수 일정 순 / 이용일 순 / 가까운 구 순(구별로 묶어서)
- 단체 전용·장애인·특정 계층(사회적 배려 등) 대상은 자동으로 숨김, 대상이 "제한없음"인 것은 어린이·가족 언급이 있을 때만 기본 노출
- 예약은 서울시 사이트에서 직접 해요. 이 앱은 로그인 정보를 받지 않아요.

## 실행

```
npm install
npm run dev          # 처음에는 샘플(실제 프로그램 10건)이 보여요
```

## 실데이터 연결

1. 서울 열린데이터광장(data.seoul.go.kr)에서 발급받은 인증키를 준비
2. 내 컴퓨터에서 한 번 확인:
   ```
   SEOUL_API_KEY=인증키 npm run collect     # public/data/courses.json 생성
   npm run dev
   ```
   인증키는 파일이나 채팅에 적지 마세요. 환경변수로만 넘겨요.
3. 자동 갱신·배포(GitHub Pages, 3시간마다):
   - 저장소 Settings > Secrets and variables > Actions > `SEOUL_API_KEY` 로 인증키 등록
   - Settings > Pages > Source 를 **GitHub Actions** 로 설정
   - push 하면 배포 → 폰 브라우저에서 "홈 화면에 추가"

## 알아둘 점

- 서울시 목록에는 회차별 날짜가 없고 이용 "기간"만 있어요. 제목·상세 글에 "매주 토" 같은 요일이 있으면 그날만,
  없으면 기간 안의 모든 날에 연하게(점선) 표시해요. 정확한 날짜는 예약 사이트에서 확인하세요.
- 거리는 직선거리(대략)예요. 기준 좌표는 `config.js` 에서 바꿀 수 있어요.

## 구글 동기화 (Firebase)

- 설정 값: `src/data/firebase.js` (공개돼도 안전한 식별 정보). 데이터는 Firestore 보안 규칙이 지켜요.
- Firestore 규칙(Firebase 콘솔 → Firestore Database → 규칙):
  ```
  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /users/{uid} {
        allow read, write: if request.auth != null && request.auth.uid == uid;
      }
    }
  }
  ```
- Authentication → 로그인 방법에서 Google 사용 설정, 설정 → 승인된 도메인에 배포 주소(`계정.github.io`) 추가.
- 요금제는 무료(Spark)로 두고 결제 수단은 등록하지 마세요.
- 합치는 규칙은 `src/lib/sync.js` (+ `test/sync.test.mjs`): 평소에는 항목별로 나중에 고친 쪽, 처음 연결할 때는 찜·숨김·메모를 합쳐요.
